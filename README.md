## 🧠 Как я работаю

1. **Архитектура.** Проектирую фреймворк: Playwright и Cypress, Page Factory, единый NPM-пакет UI + API для всех проектов компании.
2. **Автоматизация.** Закрываю UI, API и backend: pytest, requests, моки — 10 000+ автотестов на трёх крупных проектах.
3. **Процесс.** Встраиваю тесты в CI/CD: пайплайны, Quality Gates, Allure Server и Telegram-отчёты.
4. **Команда + AI.** Cursor и LLM для Page Objects и локаторов; найм, менторство и code review — два отдела с нуля, 4 и 3 человека.
